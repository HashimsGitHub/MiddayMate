# API Requirements

## User Endpoints
- POST /auth/login
- GET /users/me
- POST /users/profile
- GET /venues
- GET /venues/:id
- GET /promotions
- POST /invitations
- GET /invitations
- POST /messages

## Vendor Endpoints
- POST /vendors
- GET /vendors/:id
- POST /promotions
- PUT /promotions/:id

## API Expectations
- Return clear error messages.
- Validate required request data.
- Support JSON payloads consistently.
