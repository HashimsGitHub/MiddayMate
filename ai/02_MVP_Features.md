# MVP Features

## Core Features
1. User authentication with OAuth support.
2. Professional profile creation.
3. Venue discovery by location.
4. Promotion and offer browsing.
5. Availability status for users.
6. Invitation flow for coffee or lunch meetups.
7. Basic chat after invitation acceptance.
8. Favourite venues and venue bookmarking.

## Out of Scope for MVP
- Advanced matching algorithms.
- Full real-time messaging.
- Payments and reservations.
- Complex analytics dashboards.
